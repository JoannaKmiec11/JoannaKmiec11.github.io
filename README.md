# Joanna Kmiec — Product Manager portfolio

Static portfolio site. Plain HTML and CSS, no build step.

## Run locally

From this folder:

```
python -m http.server 8000
```

Then open http://localhost:8000/

## Structure

- `index.html` — landing page
- `case-studies/` — one page per case study
- `shared/` — brand tokens, base styles, logos
- `assets/` — images, diagrams and the CV

## Deployment

Hosted on GitHub Pages from the `main` branch root.
